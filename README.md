# DoJang - Your ultimate task master!
It’s truly just a simple task manager! You can add, delete, and edit tasks!
## Run Locally

Clone the project

```bash
git clone https://link-to-project
```

Go to the project directory

```bash
cd my-project
```

Install dependencies

```bash
npm install
```

Start the server

```bash
npm run dev
```


## FAQ

#### Q1. Can I use Markdown?

Yes, you can! We support basic Markdown syntax. Please refer to the guide on [this page](https://www.markdownguide.org/cheat-sheet/) for more details.

#### Q2. What login methods are available?

Currently, email login is the only option. We plan to add Google login in the future.
